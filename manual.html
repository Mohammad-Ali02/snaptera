HEN supertargeting in Excel

1. Overview

SnapTarget performs pinch-analysis supertargeting inside Microsoft Excel: minimum hot/cold utility and pinch location (Problem Table Algorithm), counter-current area targets (Bath formula), minimum number of units, shells and Ft estimates, and a full ΔTmin trade-off study with two capital-cost models — plus seven live charts, one per sheet.

It is a pure-VBA port of a validated Python supertargeting model and reproduces it to machine precision (worst relative deviation 4×10−15 over the full ΔTmin sweep); the underlying energy and area targets are cross-validated against OpenPinch.

Naming note: SnapTarget is currently distributed as SuperTarget.xlam (v2.4) and its ribbon tab is labeled SuperTarget — the original name from the graduate research it grew out of. Same tool; the file and ribbon will adopt the SnapTarget name in a future release.

2. Installation

Try it once: double-click SuperTarget.xlam and enable macros when prompted.

Install permanently: Excel → File → Options → Add-ins → Manage: Excel Add-ins → Go… → Browse… → select the file. If Windows blocks the download, right-click the file → Properties → Unblock first.

Workbooks created with SnapTarget use its worksheet functions, so they display #NAME? on machines where the add-in is not installed.

3. Quick start

StepRibbon buttonWhat you get
1New TemplateA Streams input workbook, pre-filled with the kerosene hydrotreater demo case (streams CMIX, C3, C4, H1–H3 + economics), plus Credits and License (MIT) sheets.
2—Set ΔTmin (cell B4) and No. of streams (E4) — the stream table instantly resizes — then enter your streams and adjust the four input boxes.
3Compute TargetsThe PTA sheet (full heat cascade, pinch highlighted) and the live Results sheet — Pinch & Energy Targets, Area & Units Targets, Cost Targets.
4Super TargetsThe supertargeting Trade-Off Study sheet (ΔTmin 0.5–40 °C, both optima highlighted live).
5ChartsSeven live charts, one per sheet (auto-builds the trade-off study first if it's missing).

Everything except the PTA sheet is live. The Results table, the Trade-Off Study, the chart curves and even the chart captions are formulas: change a stream, ΔTmin or an economic parameter and they all recalculate — no button re-run needed. The PTA cascade is a snapshot (its row structure depends on the stream count); re-run Compute Targets to refresh it.

The input template has the stream table on the left, four labeled input boxes on the right, and two control cells at the top:

6. Output sheets

PTA — Problem Table Algorithm

Shifted interval temperatures (hot −ΔTmin/2, cold +ΔTmin/2), the infeasible cascade whose most-negative value fixes QH,min, and the feasible cascade — zero at the pinch, QC,min at the bottom. The pinch row is highlighted.

Results (live)

Three sections — Pinch & Energy Targets, Area & Units Targets, Cost Targets. Every quantity is a live ST_TARGET formula on the ΔTmin cell.

Trade-Off Study (live)

The ΔTmin sweep, 0.5–40 °C. The green row marks the targeting-level optimum (minimum TAC with pure counter-current area); the blue row marks the design-adjusted optimum (minimum TAC with Ft + shells correction). The highlighting is conditional formatting, so it moves automatically when the inputs change.

Column groupMeaning
QH,min / QC,min / QrecPTA energy targets and process-to-process heat recovery at each ΔTmin.
Area / NuBath-formula counter-current area target and minimum number of units (Euler, MER).
OPEX / ACAPEX (t) / TAC (t)Utility cost, annualized capital and total annualized cost of the targeting-level model.
Nsh / Ft / Area (Ft)Estimated 1–2 shells, average LMTD correction factor, Ft-corrected area.
ACAPEX (d) / TAC (d)Annualized capital and TAC of the design-adjusted model (shells + Ft).

Charts (live, one per sheet)

Composite Curves, Shifted Composites, Grand Composite, Trade-Off (Targeting), Trade-Off (Design), Energy Targets, Area Targets. All seven read their data and captions from formulas: titles show the current QH/QC/Qrec, pinch and optima and follow every input change.

8. Methodology & validation

  • Energy targets: Problem Table Algorithm on shifted temperatures.
  • Area target: Bath formula (vertical heat-transfer model) on balanced composite curves with the Chen LMTD approximation and stream-individual film coefficients.
  • Units target: Euler (N−1) with MER pinch decomposition.
  • Design adjustment: shells power-law and Ft = 1 − 0.8·exp(−0.25·ΔTmin), floored at 0.30 (Ahmad–Linnhoff–Smith supertargeting).
  • Economics: per-unit capital cost law annualized with the capital recovery factor.

The two cost models bracket reality: the targeting-level model assumes pure counter-current exchangers at the minimum unit count, so its optimum sits at a very small ΔTmin; the design-adjusted model adds the Ft correction and a shells estimate, which penalizes small approach temperatures and moves the optimum to a practical value — in agreement with the Aspen Energy Analyzer result (≈ 9 °C) for the demo plant.

The VBA engine reproduces its validated Python parent model — 34 ΔTmin points × 14 quantities — to a worst relative deviation of 4×10−15 (machine precision); energy targets agree with OpenPinch within 0.04 % and area targets within 6 %.

9. Troubleshooting

SymptomCause & fix
Ribbon tab doesn't appearMacros are disabled or the file is blocked. Enable macros when prompted, or right-click the .xlam → Properties → Unblock, then re-open Excel.
#NAME? in results cellsThe add-in isn't installed on this machine — the workbook's formulas call its functions. Install the .xlam (section 2).
#VALUE! from a functionNo Streams sheet in the workbook, a malformed stream table (missing temperatures/CP), or ΔTmin ≤ 0. Fix the inputs; the functions recover automatically.
Results don't update after editing streamsCalculation is set to Manual — press F9 or switch Formulas → Calculation Options → Automatic. Remember the PTA sheet is a snapshot: re-run Compute Targets.
Stream table has the wrong number of rowsSet the No. of streams box (E4) — the table resizes itself; rows dropped when shrinking are cleared.
